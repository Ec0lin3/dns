# Stock Scanner Bot

בוט לסריקת מניות בבורסה האמריקאית לפי קריטריונים טכניים ו-ICT,
עם דשבורד ניהול בדפדפן והתראות טלגרם.

## מה הבוט עושה

- סורק את מניות **S&P 500 / Nasdaq 100** (או רשימה מותאמת אישית).
- בודק לכל מניה: ממוצעים נעים, FVG, נזילות (Liquidity), Range/Equilibrium, ופערים (Gaps).
- כל קריטריון מוגדר כ-**חובה / בונוס / כבוי**, ותומך בריבוי בדיקות (multi-timeframe — למשל FVG שבועי + יומי).
- מחזיר רשימת מניות שעברו את הסינון, ממוינת לפי ניקוד.
- שולח את התוצאות לטלגרם, ידנית או בתזמון אוטומטי בסוף יום מסחר.

## התקנה

נדרש Python 3.10+.

```bash
cd stock_scanner
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

פתח בדפדפן: <http://127.0.0.1:8000>

| חלק | מה אפשר להגדיר |
|------|----------------|
| יקום המניות | S&P 500 / Nasdaq 100 / שניהם / רשימה ידנית |
| ניקוד וסינון | סף ניקוד הבונוס המינימלי למעבר |
| קריטריוני סריקה | מצב (חובה/בונוס/כבוי), משקל, וכל הפרמטרים לכל קריטריון |

לחיצה על **שמור הגדרות** כותבת ל-`config.json`. **סרוק עכשיו** מריץ סריקה מיידית.

### לוגיקת הסינון

מניה עוברת כאשר **כל** קריטריוני ה'חובה' מתקיימים **וגם** סכום נקודות הבונוס ≥ הניקוד המינימלי.
לכל קריטריון רב-בדיקות (ממוצעים / FVG / נזילות) אפשר לבחור אם נדרש שכל הבדיקות יתקיימו (AND) או לפחות אחת (OR).

### הקריטריונים

- **ממוצעים נעים** — מחיר מעל/מתחת לממוצע, חציית ממוצעים (Golden/Death), או מחיר קרוב לממוצע.
- **FVG** — Fair Value Gap (תבנית 3 נרות): קיום FVG פתוח, או מחיר בתוך ה-FVG. נתמך בכל טיימפריים.
- **נזילות** — סווינגים: נזילות לא-נגועה מעל/מתחת, או גריפת נזילות. עוצמת סווינג גבוהה = נזילות חיצונית, נמוכה = פנימית.
- **Range / Equilibrium** — ננעל אוטומטית על סווינג-נמוך וסווינג-גבוה משמעותיים אחרונים (מבנה אמיתי, לא חלון נרות קבוע), מחשב את ה-50% (EQ), ובודק אם המחיר ב-Discount / Premium / Equilibrium. באזור Equilibrium אפשר לבחור התראה לפי **מחיר הסגירה** ברצועה, או לפי **נגיעת הנר** (wick) ברצועה גם אם נסגר מחוצה לה.
- **פערים (Gaps)** — אזור הפער בין נר לנר, לפי כיוון וגודל מינימלי. מצב: לא מולא / מולא / **מחיר בתוך הגאפ (כניסה)** / כל פער. מצויר על הגרף כאזור מוצלל ורוד, נפרד מ-FVG.
- **תמיכה / התנגדות** — קווים אופקיים במחיר של נקודות קיצון, וקו מגמה אלכסוני מהשפל/שיא המשמעותי דרך נקודת קיצון מאוחרת יותר, שנמתח קדימה מעבר לנר האחרון. הקריטריון עובר כשהנר הנוכחי נוגע בקו בטווח הסבולת.

### גרף לכל מניה

לחיצה על מניה בטבלת התוצאות פותחת **גרף נרות (TradingView Lightweight Charts)** עם כל מה שהבוט זיהה: ממוצעים, קופסאות FVG, אזורי גאפ, נקודות נזילות, רמות Range, וקווי תמיכה/התנגדות — לצד **מקרא** שמסביר כל סימון. אפשר להחליף את הטיימפריים של הגרף.

### דף בדיקת מניה

טאב **🧪 בדיקת מניה** מאפשר לבחור מניה בודדת, לסמן אילו פונקציות לזהות, וללחוץ "בדוק" — מתקבלת טבלה שמראה מה זוהה לכל פונקציה, יחד עם הגרף והסימונים. הפרמטרים של כל פונקציה נלקחים מדף הניהול.

## הגדרת בוט טלגרם

1. בטלגרם, פתח שיחה עם **@BotFather** ושלח `/newbot` — עקוב אחר ההוראות וקבל **Bot Token**.
2. שלח הודעה כלשהי לבוט החדש שיצרת.
3. פתח בדפדפן: `https://api.telegram.org/bot<TOKEN>/getUpdates` ומצא את הערך `"chat":{"id": ...}` — זה ה-**Chat ID**.
4. הזן את ה-Token וה-Chat ID בדשבורד, סמן "שלח התראות", ולחץ **שלח הודעת בדיקה**.

## מקור הנתונים

הנתונים נמשכים מ-Yahoo Finance דרך `yfinance` (חינמי, ללא מפתח API).
מתאים לנרות יומי/שבועי/חודשי וגם אינטרא-דיי מוגבל. הנתונים נשמרים במטמון ל-15 דקות;
"נקה מטמון" מאלץ משיכה טרייה.

## הערות

- `config.json` (כולל ה-Token) ו-`app/_cache/` אינם נכנסים ל-git.
- yfinance אינו מקור נתונים רשמי — לשימוש מסחרי מומלץ ספק נתונים בתשלום.
- הבוט נועד למחקר וסינון בלבד, ואינו ייעוץ השקעות.
